# আমার সংগ্রহ

লিংক, ভিডিও, ছবি ও পিডিএফের আলাদা আলাদা বিভাগ ও আলাদা আপলোড ফর্ম।

- **সবাই** লিংক যোগ করতে এবং ফাইল আপলোড করতে পারে, কোনো লগইন লাগে না।
- **মোছা যায় শুধু অ্যাডমিন পাসওয়ার্ড দিয়ে।** সাধারণ দর্শক কোনো মোছার বোতাম দেখে না, আর সার্ভারও তাদের অনুরোধ ফিরিয়ে দেয়।
- ভিডিও ডিফল্টে ২ জিবি পর্যন্ত। ফাইল ৮ এমবির টুকরোয় যায়, নেট কেটে গেলে একই ফাইল আবার বেছে নিলে যেখান থেকে থেমেছিল সেখান থেকে চলে।
- কোনো বাইরের প্যাকেজ লাগে না। শুধু Node.js (১৮ বা নতুন) দরকার।

## চালানোর নিয়ম

```bash
cd amar-sangroho
ADMIN_PASSWORD="আপনার-শক্ত-পাসওয়ার্ড" node server.js
```

এরপর ব্রাউজারে http://localhost:3000 খুলুন। ADMIN_PASSWORD না দিলে সার্ভার নিজে একটা পাসওয়ার্ড বানিয়ে ছাপিয়ে দেয় এবং `data/admin-password.txt` ফাইলে রাখে।

**মোছার জন্য:** পাতার ওপরে ডানে "অ্যাডমিন" চাপুন, পাসওয়ার্ড দিন। তখন প্রতিটি আইটেমে "মুছুন" বোতাম আসবে। কাজ শেষে "অ্যাডমিন মোড · বের হন" চাপুন।

## সেটিংস (পরিবেশ ভ্যারিয়েবল)

| নাম | ডিফল্ট | কাজ |
|---|---|---|
| ADMIN_PASSWORD | নিজে বানায় | অ্যাডমিন পাসওয়ার্ড |
| PORT | 3000 | পোর্ট |
| MAX_VIDEO_MB | 2048 | ভিডিওর সর্বোচ্চ সাইজ (এমবি) |
| MAX_IMAGE_MB | 50 | ছবির সর্বোচ্চ সাইজ |
| MAX_PDF_MB | 200 | পিডিএফের সর্বোচ্চ সাইজ |
| MAX_TOTAL_GB | 100 | পুরো সাইটের মোট জায়গার সীমা |
| UPLOADS_PER_HOUR | 30 | এক আইপি থেকে ঘণ্টায় কয়টি ফাইল |
| LINKS_PER_HOUR | 60 | এক আইপি থেকে ঘণ্টায় কয়টি লিংক |
| DATA_DIR | ./data | ফাইল ও তথ্য রাখার ফোল্ডার |
| TRUST_PROXY | 0 | nginx/Caddy-র পেছনে চালালে 1 দিন |
| COOKIE_SECURE | 0 | HTTPS চালু থাকলে 1 দিন |

MAX_TOTAL_GB আপনার ডিস্কের খালি জায়গার চেয়ে কম রাখুন।

## সবার জন্য খোলা সার্ভারে দেওয়ার সময়

1. একটি VPS নিন (যেকোনো Linux, Node.js ১৮+), ফোল্ডারটি তুলে দিন।
2. **HTTPS দিন।** সবচেয়ে সহজ Caddy:
   ```
   yourdomain.com {
       reverse_proxy localhost:3000
   }
   ```
   তারপর `TRUST_PROXY=1 COOKIE_SECURE=1` সহ সার্ভার চালান।
3. **nginx ব্যবহার করলে** অবশ্যই `client_max_body_size 16m;` দিন। ডিফল্ট ১ এমবিতে আপলোড আটকে যায়।
4. **Cloudflare ব্যবহার করলে** সমস্যা নেই। এখানে প্রতি অনুরোধ মাত্র ৮ এমবি, তাই ১০০ এমবির সীমার মধ্যে থাকে।
5. সার্ভার বন্ধ হলে নিজে চালু রাখতে pm2 বা systemd ব্যবহার করুন, যেমন `pm2 start server.js --name sangroho`।
6. **ব্যাকআপ:** পুরো `data` ফোল্ডারটাই আপনার সব ফাইল ও তালিকা। নিয়মিত কপি রাখুন।

## নিরাপত্তায় যা আছে

- মোছা, লগইন ছাড়া অসম্ভব। পাসওয়ার্ড ভুল দিলে ১৫ মিনিটে ১০ বারের বেশি চেষ্টা করা যায় না।
- ফাইলের ভেতরের বিষয়বস্তু যাচাই হয়, তাই ".exe" নাম বদলে ".pdf" করে দিলে ঢোকে না।
- শুধু MP4, WebM, PNG, JPG, GIF, WebP ও PDF নেওয়া হয়। ফাইল সার্ভারে র‍্যান্ডম নামে থাকে।
- এক আইপি থেকে ঘণ্টায় আপলোডের সংখ্যা সীমিত, আর মোট জায়গারও সীমা আছে।
- সবার জন্য খোলা সাইটে কেউ অযাচিত জিনিস দিতে পারে। নিয়মিত দেখে অ্যাডমিন হিসেবে মুছে দিন।

## ফাইলের গঠন

- `server.js`: সার্ভার
- `public/`: সাইটের পাতা (index.html, app.js, styles.css)
- `data/`: প্রথমবার চালালে তৈরি হয় (ফাইল, তালিকা)
